# 設定画面の再設計・ページヘッダー統一

## 利用者に見える変更

- 設定は「出口基準」「重大度と種別」「役割と承認」「AI送信先」の4タブで切り替える。入力値はタブ移動で失われない。
- 出口基準は3つのプリセットと重大度ごとの上限を比較して選ぶ。右側に現在の判定への影響と、保存前後の差分を表示する。
