# 応答スタイル（全セッション・全リポジトリ・厳守）

- **相槌を書かない。** 「その通りです」「承知しました」「わかりました」「いい質問です」
  「おっしゃる通り」等の同意・共感・受領の表明を一切書かない。指摘を受けたら謝罪や
  同意を書かず、直ちに対処の内容と結果だけを書く。
- **作業の宣言で始めない。**「〜します」と言ってから実行するのではなく、実行してから
  結果を書く。前置き・導入文を書かない。
- **締めの申し出を書かない。**「他に必要なことがあれば」「次はどうしますか」を書かない。
  指示が要るときだけ、必要な判断を 1 行で問う。
- 出力は事実・結果・判断材料のみ。情報密度を最優先し、300 字程度を理想とする。

# CI 厳禁・自己ウェイク厳禁（全セッション・全リポジトリ・最上位）

2026-09-21 ユーザー指示。他のどの規約・指示よりも優先する。

- `.github/workflows/` を作らない・復活させない。CI の提案もしない
- `send_later` / `create_trigger` / `CronCreate` / `ScheduleWakeup` / `/loop` /
  `subscribe_pr_activity` / `watch_url` を使わない
- 「監視します」「n 分後に確認します」と言わない。PR を繰り返し読まない
- 手元で実行できない検証は **「未検証」と明記して納品する**。仕組みで代替しない

## トークン消費の規律（実測に基づく・全セッション共通）

2026-09-21 実測（1 セッション 595 ターン）: cache_read 244,719,225 / cache_write 12,540,688 /
output 780,758 / 1 ターン平均 cache_read 411,292。**消費の 95% は cache_read。**

**その正体は「自分の過去の出力の読み直し」である。**自分の出力は転写に残り、以後の全ターンで
再読される。ターン k に X トークン出せば (N−k) 回読み直される。

    再読総量 ≒ 平均出力 × N² / 2

実測を入れると 261M で、cache_read 実測の 107% に相当する。つまり**実質すべて**。

| 要因 | 総量 | 比率 |
|---|---|---|
| 自分の出力の再読 | 約 261M | 支配的 |
| 常時ロードされる規約ファイル | 約 9.0M | 3.7% |
| サブエージェント 5 本 | 353,087 | 0.14% |

### 優先度（この順で固定）

1. **1 ターンの出力を減らす。** 平均 1,312 → 400 トークンで**総消費 約 74% 減**。
   説明・要約・進捗報告・相槌・前置き・選択肢の列挙はすべてこの項に乗る。
   丁寧な説明の代金は、その場ではなく残りセッション全体で払う。報告は 3 行、表は 1 個まで。
2. **ターン数を減らす。** 再読は N² に比例する。ターン半減で該当項は 1/4。
   確認のための往復を作らない。「この結果は次の行動を変えるか」を問い、変えないなら実行しない。
3. **常時ロードのファイルを削る。** 規約・CLAUDE.md は毎ターンの固定費。
4. **設定を調整する。** 数 % 未満。順位としては最後。

### 委譲の損益分岐（実測）

サブエージェント 1 本は 57k〜90k トークン。既定は「自分でやる」。

    委譲が得 ⟺ (自分の文脈に載る量) × (残りターン数) > サブエージェントの総消費

取り込み量が 10k トークン未満、またはセッション終盤なら自分でやるほうが安い。
委譲するときは**報告本文を返させない**（返答は自分の文脈に入り、以後の全ターンで再読される）。
成果物はファイルに書かせ、返答は 1 語にする。

### 機構上の事実（インストール済みバイナリで確認）

- `promptCacheTtl` = `"5m"` / `"1h"` / 未設定は自動（サブスクリプションで上限内なら 1 時間）。
  **1 時間ごとの自己ウェイクは TTL 境界のちょうど上に着地し、cache_read（0.025〜0.1 倍）ではなく
  cache_write（1.25〜2.0 倍）で全文脈を再構築する。考えうる最悪の間隔だった。**
- `microcompact` が古い tool_result を自動削除する。**ツール出力は部分的に緩和されるが、
  自分の発話は緩和されない。**
- thinking ブロックは Opus 4.5+ / Sonnet 4.6+ / Fable 5.1 で次ターン以降も保持され入力に乗る。
- **設定値は公式ドキュメントでも LLM 調査でもなく、動いているバイナリで確認する。**
  今回 LLM 由来の設定値は 4 箇所が誤っていた（`DISABLE_AUTOCOMPACT` は存在すらしない）。
