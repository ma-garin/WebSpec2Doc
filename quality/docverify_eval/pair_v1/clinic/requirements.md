# 要件定義書 さくら町診療所 受付・診察予約システム

## 1 目的・範囲

### 1.1 目的

さくら町診療所（架空の診療所）の受付業務と診察予約を電子化する。
電話での予約受付を減らし、患者の待ち時間と職員の転記作業を減らすことを目的とする。

### 1.2 範囲

- 対象: 診察の予約、来院受付、休診日の管理、患者情報の管理、予約件数の集計
- 対象外: 会計、電子カルテ、処方、検査結果の通知
- 利用者: 患者、職員の2種類とする
- 対象診療科: 内科、小児科、整形外科、皮膚科の4科とする

## 2 用語

| 用語 | 意味 |
|---|---|
| 患者 | 本診療所で診察を受ける人、または受けようとする人 |
| 職員 | 本診療所の受付担当者と事務担当者 |
| 予約枠 | 予約1件が占める診察の時間帯の単位 |
| 予約番号 | 予約の確定時に発行する8桁の数字 |
| 受付番号 | 来院受付の完了時に発行する当日限りの3桁の数字 |
| 来院受付 | 来院した患者が受付端末で到着を登録する操作 |
| 休診日 | 診療科ごとに診察を行わない日 |

## 3 機能要件

### 3.1 予約

- **REQ-001** 患者は、診療科・日付・時間帯を選んで診察を予約できる。

- **REQ-002** 予約できる期間は、当日を含めて30日先までとする。

- **REQ-003** 予約枠の長さと定員は、診療科ごとに表3-1のとおりとする。

表3-1 診療科と予約枠

| 診療科 | 診察時間帯 | 予約枠の長さ | 定員 |
|---|---|---|---|
| 内科 | 8:30〜12:00 / 14:00〜18:00 | 15分 | 1名 |
| 小児科 | 8:30〜12:00 / 14:00〜17:00 | 10分 | 1名 |
| 整形外科 | 9:00〜12:00 / 14:00〜18:00 | 20分 | 1名 |
| 皮膚科 | 9:00〜12:00 | 10分 | 1名 |

- 同一の患者は、同じ日に同じ診療科の予約を重複して登録できない。

- **REQ-004** 予約を確定したとき、システムは8桁の数字の予約番号を発行する。

- **REQ-005** 患者は、予約番号と生年月日を入力して予約内容を照会できる。

- **REQ-006** 患者は、診察日の前日17時までであれば予約をキャンセルできる。

- **REQ-007** 予約の確定・キャンセルのとき、システムは患者のメールアドレスへ確認メールを送信する。

- **REQ-008** 診察日の前日18時に、システムは患者の携帯電話へSMSでリマインドを送信する。

### 3.2 来院受付

- **REQ-009** 来院した患者は、受付端末で予約番号を入力して来院受付を行える。

- 来院受付が完了したとき、システムは当日の受付番号（3桁）を発行する。

- **REQ-010** 予約のない患者は、受付端末で当日診察の順番待ちを登録できる。

- 来院受付は、予約時刻の30分前から予約時刻の15分後まで受け付ける。

- **REQ-011** 職員は、受付済みの患者の受付番号と待ち人数を一覧で確認できる。

### 3.3 休診日の管理

- **REQ-012** 職員は、診療科ごとに休診日を登録でき、休診日の予約枠は予約できない状態にする。

- 予約済みの日に休診が登録されたとき、システムは該当する予約の一覧を職員に表示する。

### 3.4 患者情報

- 職員は、患者を新規登録できる。患者IDは8桁の数字で採番する。

- **REQ-013** 職員は、患者の氏名・生年月日・電話番号・メールアドレスを更新できる。

### 3.5 集計

- 職員は、日別の予約件数と来院件数をCSVファイルで出力できる。

## 4 非機能要件

### 4.1 性能

- **REQ-014** 予約画面の操作は、同時接続20人のとき95%の操作が3秒以内に完了すること。

### 4.2 可用性

- **REQ-015** 診察時間帯（8:30〜18:00）の稼働率は99.5%以上とする。

- 障害が発生したときは、速やかに復旧すること。

### 4.3 使用性

- 患者向けの画面は、高齢の患者にも直感的に操作できること。

### 4.4 セキュリティ

- **REQ-016** 患者情報は、通信時にTLS1.2以上で暗号化し、保存時にも暗号化する。

- **REQ-017** 職員による患者情報の参照・更新は操作ログに記録し、3年間保管する。

### 4.5 保全性

- データベースは毎日1回バックアップを取得し、7世代を保持する。

## 5 制約

- 本システムは院内LANと公衆インターネットの両方から利用できる構成とする。
- 患者向け画面は、パソコンのWebブラウザで利用する。
- 電子カルテとは連携しない。
- 利用者の認証は、患者は予約番号と生年月日、職員は職員IDとパスワードで行う。
- 運用開始時の登録対象は、診療科4科、職員10名とする。
- 本書に記載のない事項は、診療所と開発側が協議して決める。
