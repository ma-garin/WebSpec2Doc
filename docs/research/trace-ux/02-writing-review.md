### Acrolinx（現 Markup AI）
- 画面の型: サイドバーに総合スコアと色付きの指摘カード。スコアを開くと目標ごとのスコアカード。
- 良い点（要約ベース）: 1〜100 の総合スコアに信号色（79 以上緑・60〜79 黄・60 未満赤）。タイトルクリックで本文の該当箇所を強調。置換候補は緑で、クリックで適用。「推奨」目標は表示するがスコアに数えない。
- 悪い点: スコアは目標スコアの平均。閾値は 1 つのサポート記事のみの情報で版により違う可能性。
- 出典: 未確認（support.markup.ai の 2 ページは 403）。検索要約: https://support.markup.ai/hc/en-us/articles/10210919666066

### Writer.com
- 画面の型: 右サイドバー。右上に会社スタイルガイド準拠スコア（満点 100）、下にカテゴリ別の提案。
- 良い点: カテゴリ（Terms・Style・Clarity・Inclusivity・Compliance 等）で束ねる。用語は色で区別（承認済=水色、使用禁止=黄、要注意=要確認、保留=承認待ち）。同じ修正は「Accept all」、「Ignore all」で一括処理。誤指摘の通報（250 語以内）。
- 悪い点: 記事は提案カードの理由文と並び順を説明していない（未確認）。
- 出典: https://support.writer.com/article/249-using-suggestions

### Microsoft Editor / Word の校正
- 画面の型: 右ペイン（F7）。「Corrections（修正）」と「Refinements（改善提案）」の 2 層。本文は赤・青・紫の下線。
- 良い点: 必須修正と任意改善を分け、種類を選んで矢印で順送り。Ignore once と Stop checking for this を分離（規則単位で止められる）。ペインを閉じても下線は残る。
- 悪い点: 無視した指摘は文書を開き直すと復活する。スコアは検索要約のみで、公式ページに記載なし（未確認）。
- 出典: https://support.microsoft.com/office/check-grammar-spelling-and-more-in-word-0f43bf32-ccde-40c5-b16a-c6a282c0d251

## 共通する成功パターン
1. 種類を色で分ける（Grammarly 4 色、Editor 赤・青・紫、Writer の用語色）。凡例を覚えさせず、下線色で理解できる。
2. 「必須の修正」と「任意の改善」を層で分ける（Editor の Corrections/Refinements、文賢の校閲/推敲、Acrolinx の推奨目標はスコア対象外）。
3. 総合スコアは 0〜100 に信号色を付け、指摘を解消すると上がる（Acrolinx、Writer、Editor）。承認・無視の反応が即座に見える。
4. 指摘カードは「該当箇所→置換候補→1 クリック適用」で完結（Acrolinx、Writer、Grammarly、Just Right!）。
5. 同種の指摘は一括処理（Writer の Accept all / Ignore all）。件数が多くても疲れない。
6. 無視は「今回だけ」と「この規則を止める」を分ける（Editor）。規則の ON/OFF（文賢、Just Right! の校正設定）で運用に合わせる。
7. 規則（用語・スタイル）は色や分類名で見せ、一覧ページを持つ（Writer の Terms/スタイルガイド公開ページ）。
8. 誤指摘の通報経路がある（Writer）。AI 指摘の信頼を保つ。

## 本製品への適用案
1. 2 層表示: 規則 1（状態を書かない）〜6 の違反を「要修正」、軽微な表記ゆれ等を「改善提案」に分け、件数は層別に出す。根拠: パターン 2。
2. 指摘カードは「どの規則か／該当箇所の引用／理由 1 文／直し方」の 4 点固定。適用は「文書へ反映」ではなく「課題として登録」（規則 3: 勝手に更新削除しないため、自動書き換えボタンは置かない）。
3. 合否は Tier 別の信号色（緑／黄／赤）と件数で出し、点数は付けない。検査の根拠が説明できる指標以外は出さない（Grammarly のスコア根拠が不明な点を反面教師とする）。確定後は課題のある文書だけを強調表示。
4. 規則 6 つを常設の「規則一覧」ページに置き、指摘カードから規則名で飛べるようにする（Writer の Terms 方式）。用語集違反は用語集の該当行へ連動。
5. 「同じ内容が 2 か所」「上位が下位を参照」のように複数文書にまたがる指摘は、両方の文書へ同じ指摘を表示し、片方クリックで相手へ移動。同種は一括で「確認済み」にでき、「この規則を今回の検査で止める」と「この指摘だけ無視」を分ける（パターン 5・6）。
