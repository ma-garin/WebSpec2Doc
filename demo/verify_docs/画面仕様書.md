## 2. 画面遷移

- P001 → P002 → P003 → P004 → P005 → P006 → P007 → P008
- P006 でキャンセルした場合は P004 へ戻る
- P007 で「入力へ戻る」を選択した場合は P006 へ戻る
- 各画面のヘッダから P001 へ戻れる
