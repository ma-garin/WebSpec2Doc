## 直さなかったこと

| 見つけたこと | 直さなかった理由 |
|---|---|
| **`/systems` の System 02 カードが `href="/test-automation"`（`?domain=` 無し）**。どのサイトを開くかはサーバ側の先頭サイト任せで、`demomart` 以外が開くことがある | `templates/system-select.html` は今回の編集許可範囲外。1 行の修正で済むので、担当者に回すのが早い |
| **失敗ステップの番号（`last.step`）が実行結果に記録されていない。**失敗サマリが「停止したステップは記録されていません」と書かざるを得ない | 記録するには `web/routes/ta2.py` の `_execute` と Playwright レポートの突き合わせが要る。推測でステップ番号を埋めるのは契約 §0 の捏造禁止に反するため、**分からないことを分からないと書く**方を選んだ。埋めるなら実行側の課題として別に立てるべき |
| **要素辞書のラベルが生のフィールド名**（`card_name` `cvc` など）。ピッカーの見出しが人間の言葉になっていない | クロール結果（`report.json` の `forms[].fields[]`）にラベルが無いことが原因で、UI 側で補うと実データにない名前を作ることになる（捏造禁止）。クローラ側の課題 |
| ステップ削除の「元に戻す」は**トーストが消えると使えない**（7 秒） | 恒久的な取り消し履歴はサーバ側にモデルが無く、契約 §2 のデータモデルを増やす話になる。今回のスコープ外 |
| 「使い方」モーダルの自動表示（`modals.js` の `maybeAutoHelp`）が**どこからも呼ばれない死んだ配線**（`emit('boot')` が存在しない） | 毎回モーダルが開くのは初回以外うるさく、`localStorage` は契約で禁止のため「1 回だけ」を実現できない。代わりに U2-10 の「次の一手」で初手の迷いを潰した。配線自体は害が無いので残置 |
| 一覧の `.st .x`（ステップ削除）が opacity:0 のまま Tab 順に入る | パス 1 の `.st:focus-within .x{opacity:1}` でフォーカス時には見えるため、実害なしと判断 |
