## 1. 納品物の範囲と前提

本書は、WebSpec2Doc プロジェクトの成果物のうち、発注者へ納品する対象を一覧化したものです。前提は次のとおりです。

- 本プロジェクトは Markdown を正本（マスター）とし、Word（`.docx`）・Excel（`.xlsx`）は正本から機械生成される派生物です（6章参照）。納品時は正本と派生物の両方を対象とします。
- ソースコードは本リポジトリ一式を対象とし、開発時にのみ使用する環境（仮想環境・キャッシュ等）は対象外とします（8章参照）。
- 本製品は **PC専用** として開発されており、納品物にもモバイル/タブレット向けの成果物は存在しません。
- 本書に記載の行数・件数・サイズは、すべて本書作成時点（2026-08-02）にコマンドで実測した値です。実装の変更に伴い、次回納品時は再実測が必要です。
- 本書自身（WS2D-DL-002）とWS2D-UM-001・WS2D-CR-001は本納品作業で新設した文書であり、以下の一覧にも含めています。

## 6. 納品物の再生成方法

Markdown を正本としているため、Office ファイルは常にこの正本から再生成します。手で編集すると正本と乖離し、次のコード変更時に更新されず陳腐化するため、手編集は行わない方針です。

### 6.1 as-built情報の抽出（`scripts/extract_asbuilt.py`）

SDLC文書のうち、コードに正解が存在する部分（エンドポイント一覧・モジュール一覧・DBスキーマ・OSSライセンス・テンプレート関係）を、AST とパッケージメタデータから機械的に抽出します。手書きすると本数の多いエンドポイント（196本）を必ず取りこぼすため、機械抽出としています。

```bash
venv/bin/python scripts/extract_asbuilt.py
```

出力: `docs/sdlc/_asbuilt/routes.json`・`modules.json`・`schema.sql`・`licenses.json`・`templates.json`

### 6.2 納品文書の生成（`scripts/build_delivery_docs.py`）

SDLC文書（Markdown正本）から、納品用のWord/Excelを生成します。

```bash
venv/bin/python scripts/build_delivery_docs.py
```

出力: 各工程ディレクトリに、正本Markdownと同じ場所へ `.docx`（全SDLC文書）・`.xlsx`（一覧・マトリクス系）を並べて生成します。

### 6.3 再生成が必要になるタイミング

- コード変更でエンドポイント・モジュール・DBスキーマ・依存パッケージに変更があったとき（6.1を先に実行）
- Markdown正本の内容を変更したとき（6.2を実行してOfficeファイルへ反映）
- 本書（WS2D-DL-002）自体も、次回納品時は2章の行数・件数を再実測して更新すること

## 8. 納品対象外の明示

以下は開発・検証専用であり、納品対象に**含めません**。

| 対象 | 除外理由 |
|---|---|
| `venv/` / `.venv/` | Python仮想環境。納品先で `requirements.txt` から再構築する |
| `node_modules/` | JavaScriptツールチェーンの依存。`package.json` から再構築する |
| `__pycache__/` / `.pytest_cache/` / `.ruff_cache/` / `.mypy_cache/` | ビルド・lint・型検査のキャッシュ |
| `.runtime/` / `.playwright-mcp/` | Playwrightブラウザ本体・E2E実行時ランタイム |
| `instance/` | 認証DB（`auth.db`）・シークレットキー等の実データ。環境固有のため納品しない |
| `output/` | クロール・AutoRun実行で生成されたユーザーデータ・スクリーンショット。動作確認用のサンプルを除き納品対象外 |
| `.DS_Store` | macOSのシステムファイル |
