## Sentry
- 3/6: Issues の保存フィルタ付きタブ（All Unresolved / For Review / Regressed / Archived / Escalating）と Saved Searches、並べ替え（Recommended 他）
- 4: 状態 Unresolved / Regressed / Archived / Escalating。担当者割当・優先度・Resolve・Archive・購読をヘッダに集約
- 5: Issue 詳細は 見出し＋イベントグラフ＋右サイドバー（初回/最終発生・リンク課題・コメント）＋本文（スタック・パンくず・タグ・コンテキスト）の 4 領域
- 5/7: 「Recommended」イベントを既定表示し、最新/最古へ移動。Share Issue は Markdown/公開リンク。添付・フィードバック・疑わしいコミットも同画面
- 2/6: 一覧は project 列・レベル色の四角・タイトルホバーでスタック先読み。env/期間は絞り込みで切替
- 未確認: 一括操作、空・エラー・読込状態、Ignore（当該ページに記載なし）
- 出典: https://docs.sentry.io/product/issues/ , https://docs.sentry.io/product/issues/issue-details/
## Playwright UI mode / Trace Viewer
- 6/4: 左にテスト一覧（ファイル→describe）、名前・@tag・project・状態（passed/failed/skipped）で絞込。各テストに実行/watch/debug
- 5: 操作リスト（locator と所要時間）＋タイムライン。ホバーで DOM スナップを切替、Before/Action/After の 3 枚で状態比較
- 5: タブ Source/Call/Log/Errors/Console/Network/Metadata/Attachments が「同じ操作」に連動。範囲選択で Console/Network が絞られ、Show all で戻る
- 5/8: Errors タブとタイムライン上の赤マーカーで失敗点へ直行。Attachments は expected/actual をスライダー比較
- 10: 全てローカル・単一ファイル（trace.zip）で完結する静かな高密度 UI（密度は記述から推測、画像未確認）
- 出典: https://playwright.dev/docs/test-ui-mode , https://playwright.dev/docs/trace-viewer
## BrowserStack Test Reporting & Analytics
- 3/10: Insights はウィジェット方式（Always failing / New failures / Flakiness / Muted の件数、Build History、Unique Errors、Failures by Folders ヒートマップ）。ドラッグで並替・サイズ変更、レイアウトはブラウザ保存
- 2/6: ダッシュボード/ビルド一覧のフィルタは project・build tag・user・folder・branch。Build Runs は status・user・tag・framework・期間。ダッシュボード絞込とウィジェット絞込は AND
- 4/7: 失敗カテゴリ（Product bug / Automation bug / Environment / No defect / To be investigated）の自動分類、defect status（open 等）、Mute/Unmute、Jira バグ起票をホバー操作で提供
- 4: 閾値超過の Alert が Insights 最上部に出て「View failed tests」で該当テストへ。Quality Gates ウィジェットあり（詳細未確認）。公開ダッシュボードは組織内共有トグル
- 5: Timeline Debugging 画面で全ログ種別を統合し過去実行と比較。テスト履歴ドットは赤/緑/灰。スクショ・動画・AI 分析の記述は未確認
- 出典: http://www.browserstack.com/docs/test-reporting-and-analytics/features/insights , https://www.browserstack.com/docs/test-reporting-and-analytics/dashboards/build-dashboards
## QA の証跡・承認ツールへ移植すべき 3 要素
1. 連動する証跡タブ（Playwright Trace Viewer・観点5）: 1 件の操作/チェック項目を選ぶと 根拠スナップ(前/後)・ログ・エラー・添付が同じ選択に追従し、範囲選択で絞れる
2. 保存フィルタ付き状態タブ（Sentry・観点4/6）: 「要レビュー／差し戻し／承認済み／再発」を保存クエリのタブにし、割当・優先度・ステータスをヘッダに集約する
3. 失敗カテゴリの分類＋Alert 直行（BrowserStack・観点4/7）: 判定理由を固定カテゴリ（製品不具合/テスト不備/環境/未調査）で分類し、閾値超過の警告から該当一覧へ 1 クリックで飛ぶ。Mute と defect 連携も承認の安全弁に使う
