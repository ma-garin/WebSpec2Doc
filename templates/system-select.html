システム選択

どのシステムを使いますか？

使うシステムを選んでください。5 つは独立したシステムです。CLI / API は画面を持たず、端末や外部システムから同じ機能を使います。

System 01 ドキュメント作成 URL を渡すと、画面仕様書・遷移図・項目定義を生成します。認証・対象範囲・前回差分にも対応。既存サイトの仕様化に。 画面仕様書遷移図 フォーム定義差分 ドキュメント作成を開く → {# テスト活動支援（System 02）は管理者のみ。押しても 403 になるカードは並べない。 #} {% if not auth_user or auth_user.role == 'admin' %} 新規 System 02 テスト活動支援 仕様書・GitHub・ソースコード・開発標準を読み取り、テスト条件とテストケースを設計します。計画から不具合分析・コード修正までを一気通貫で。 テスト設計トレーサビリティ GitHub 連携不具合分析 テスト活動支援を開く → {% endif %} 独立システム System 03 AutoRun ベテラン QA として、受領から実行完了レポートの納品まで。フル QA を止めずに回し、未検証は明記・不在は証明しません。 テスト計画設計・ケース 実行・証跡カバレッジ AutoRun を開く → 画面なし System 04 CLI / API 同じ機能を端末と REST API から。ブラウザを開かずに解析・AutoRun・テスト実行まで回せます。CI や外部システムからの呼び出しに。 CI 組み込みREST API JSON 出力終了コード CLI / API の使い方を見る → 新規 System 05 テスト自動化 コードを書かずにテストのステップを組み立て、実ブラウザで実行します。実行環境の切り替えと実行傾向の確認もここから。 ノーコード編集自己修復 ビジュアル回帰実行傾向 テスト自動化を開く →

5 つは別システムです。入口・世界観・ナビは独立し、共通はログインとアカウントだけ。いつでもこの画面に戻って切り替えられます。CLI / API は画面を持たず、端末や外部システムから同じ機能を使います。
