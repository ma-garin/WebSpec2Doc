# 電子申請システム 要件定義書（各種届出）

- 文書名: 電子申請システム 要件定義書
- 版: 1.0
- 作成日: 2026-10-01
- 対象組織: みどり市（架空の自治体）

## 1 目的・範囲

### 1.1 目的

本書は、みどり市が住民に提供する各種届出の電子申請システム（以下「本システム」）の要件を定める。
窓口へ来庁せずに届出を提出できるようにし、窓口の受付件数を減らすことを目的とする。

### 1.2 範囲

- 対象: 住民による申請、審査担当者による審査、管理者による運用管理
- 対象外: 手数料の電子決済、証明書の郵送発行

### 1.3 対象利用者

- 申請者: 届出を行う住民
- 審査担当者: 申請を審査する市職員
- 管理者: 本システムの運用を管理する市職員

### 1.4 前提条件

- 申請者は、メールを受信できる電子メールアドレスを持っている。
- 審査担当者と管理者は、市の庁内ネットワークから本システムを利用する。
- 住民基本台帳の正本は、既存の住民基本台帳システムが保持する。

## 2 用語

| 用語 | 意味 |
|---|---|
| 申請 | 各種届出を電子的に提出すること |
| 申請者 | 申請を行う住民 |
| 審査担当者 | 申請を審査する市職員 |
| 管理者 | 本システムの運用を管理する市職員 |
| 受付番号 | 申請の受理時に発行する識別番号 |
| 補正依頼 | 申請の不備を理由に、審査担当者が修正を求めること |
| マイページ | 申請者が自分の申請を確認する画面 |
| 処理期限 | 受付から審査完了までに許される営業日数 |

## 3 機能要件

### 3.1 利用者登録・認証

- REQ-001 申請者は、メールアドレスとパスワードでマイページの利用者登録ができること。
- REQ-002 ログイン時にパスワードを連続して5回誤ると、そのアカウントを30分間ロックすること。

### 3.2 申請

- REQ-003 申請者は、申請種別の一覧から届出の種類を選んで申請を開始できること。申請種別ごとの処理期限と署名要否は表1のとおりとする。
- REQ-004 申請者は、入力途中の内容を下書きとして30日間保存できること。
- REQ-005 申請者は、PDF、JPEG、PNG の形式で、1ファイル10MB以下のファイルを最大5ファイルまで添付できること。
- REQ-006 本システムは、入力内容を確認画面に表示し、申請者が確定操作をした後に申請を送信すること。
- REQ-007 本システムは、申請を受理した時点で受付番号を発行し、受付完了メールを5分以内に申請者へ送信すること。
- REQ-008 申請者は、申請の状況（受付済、審査中、補正依頼、完了、差戻し）をマイページで確認できること。
- 申請者は、審査担当者が審査に着手する前の申請を、自分で取り下げできること。
- 申請者は、過去の申請を受付番号で検索できること。
- 申請者は、受付済みの申請内容の控えをPDFでダウンロードできること。
- 本システムは、電子署名を要する申請種別では、申請の確定時に署名用電子証明書による電子署名を求めること。署名要否は表1の「署名要否」列で定める。

表1 申請種別と処理期限

| 申請種別 | 処理期限 | 署名要否 |
|---|---|---|
| 住所変更届 | 5営業日 | 要 |
| 世帯主変更届 | 5営業日 | 要 |
| 転出届 | 3営業日 | 要 |
| 犬の登録届 | 10営業日 | 不要 |
| 事業所変更届 | 10営業日 | 不要 |

### 3.3 審査

- REQ-009 審査担当者は、未処理の申請を処理期限が近い順に一覧で確認できること。
- REQ-010 審査担当者は申請を承認するか、不備の理由を付けて補正依頼にできること。
- REQ-011 補正依頼を受けた申請者は、補正依頼の日から14日以内に内容を修正して再提出できること。14日を過ぎた申請は差戻しとすること。
- REQ-012 審査担当者は、審査結果を速やかに申請者へ通知すること。

### 3.4 運用管理

- 管理者は、表1の処理期限を超過した申請を一覧で確認できること。
- 管理者は、申請種別ごとの月次の受付件数をCSV形式で出力できること。
- 本システムは、すべての操作について、操作者、日時、操作内容を操作ログとして記録すること。

## 4 非機能要件

### 4.1 性能・可用性

- REQ-013 同時接続200ユーザーの状態で、画面の表示は95パーセンタイルで3秒以内に完了すること。
- REQ-014 稼働率は月間99.5%以上とする。ただし、事前に通知した計画停止の時間は除く。

### 4.2 セキュリティ

- REQ-015 申請者の端末と本システムの間の通信は、TLS 1.2 以上で暗号化すること。
- 申請データと操作ログは、受付日から10年間保存すること。

### 4.3 利用性

- REQ-016 画面は、申請者にとって使いやすいこと。
- 本システムは、Microsoft Edge、Google Chrome、Safari の最新2世代で動作すること。

## 5 制約

- 個人情報の取り扱いは、みどり市個人情報保護条例に従うこと。
- 住民基本台帳システムとの連携は、1日1回のファイル連携とすること。
- 本システムは、市が契約するクラウド環境の国内リージョンで稼働させること。
- 申請者への通知手段は、電子メールとする。
- 公開開始は2027年4月1日とする。
