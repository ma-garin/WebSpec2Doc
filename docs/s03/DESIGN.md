# S03 AutoRun 結果ページ 設計（2026-10-24）

## 画面 × 状態
| 画面 | 状態 | 表示 | 担当 |
|---|---|---|---|
| 結果レポート | 通常 | 判定と証跡・工程バー | S03 |
| 結果レポート | 読込中 | 読み込んでいます | S03 |
| 結果レポート | 0件 | 未実行と次の行動 | S03 |
| 結果レポート | 失敗 | 原因文と再読込 | S03 |
| 結果レポート | 権限不足 | 共通の 403 | 共通 |
| 結果レポート | 検索0件 | 対象外 | — |
| 結果レポート | 未保存 | 対象外 | — |
| 結果レポート | 競合 | 対象外 | — |
| 結果レポート | 復元 | 対象外 | — |

- 結果ページは閲覧専用のため、未保存・競合・復元・検索0件は発生しない。
- 実行の終わり方 7 種（未実行・完了・途中停止・時間切れ・ログイン壁・部分結果・中止）を利用者向けの文で出し分ける。

## 業務フロー
入口 /autorun/report/<対象> → API /api/autorun/report/<対象>?section=verdict
→ web/services/autorun_verdict.build_verdict → 出力 qa_process の stages.json・playwright_report.json・run_record(.prev).json
→ 保存: 実行終了時に auto_run_job._notify_finished_once から autorun_run_record.save_run_record が run_record.json を書き、前回分を run_record.prev.json に退避
→ エラー文: 対象なし 404「この対象の成果物が見つかりません」／読込失敗「結果を読み込めませんでした。時間をおいて再読み込みし…」

## 今回変える点
- 工程バー（1〜8 の段階承認＋9 実行）を常時表示。各段の出口条件・担当・判断（誰が・いつ・理由）を「判定と証跡」に表で出す。
- 認証なしの承認は「本人確認なし（承認として数えません）」と表示し、判定帯で名指しする。
- 実行ログを右パネルに常時表示（折りたたみなし）。実行終了時にログ・未確認事項を保存する。
- 下部判定帯: 「全体」「今回の変更分」を別行で、共通語彙（合格／不合格／判定不能／未判定）と名指し項目を出す。
- 表示確認の切替（通常／読込中／0件／失敗）と data-state。

## 変えない点
- 既存セクション（ダッシュボード〜実行結果）の中身と API 形式。段階承認 API（autorun_stages.py）。
