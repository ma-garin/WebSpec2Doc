# S06-1 対検査レビュー Blueprint の正式登録

- 対象ファイル: web/__init__.py（共通・編集禁止）
- 変更内容: import 群に `doc_verify_pair` を追加し、`app.register_blueprint(doc_verify_pair.bp)` を doc_verify 群の直後に 1 行追加する。
- 理由: 既存の doc_verify 群は個別に register_blueprint されており、自動登録の仕組みが無い。
- 暫定対応: web/routes/doc_verify.py 末尾で `doc_verify_pair.register(bp)` を呼び、同じ URL を既存 Blueprint に載せている。
- 正式登録後に行うこと: 上記の暫定 3 行を doc_verify.py から削除する（両方残すとエンドポイント名は別だが URL が二重登録になる）。
- 影響範囲: /api/docverify/<iid>/pair/* のみ。既存 URL は変わらない。
