実装前に決めたいこと

Q1. 既存の spec.xlsx にシートを足す形でよいですか。
別ファイル（例: test_spec.xlsx）に分ける案もありますが、 1ファイルで渡せるほうが納品物として扱いやすいと考え、既存ブックへの追加を推しています。 エクスポートのドロップダウンも「Excel」1項目のままになります。
Q2. シートの並び順はこの案（画面仕様 → テスト設計 → テストケース → 遷移表）でよいですか。
「読む → 設計する → 実行する」という画面のタブ順に合わせています。
Q3. テストケースの「結果」列（未実行/PASS/FAIL）も含めますか。
含める案にしています。実行済みなら実績が、未実行なら「未実行」が入ります。
