# 社内研修 学習管理システム 要件定義書

## 1 目的・範囲

### 1.1 目的

社内研修の申込、受講、確認テスト、修了証の発行までを一つのシステムで管理する。
受講状況を上長と管理者が把握できるようにし、必須研修の受講漏れを減らす。

### 1.2 範囲

- 対象利用者は全社員とする。
- 対象業務は研修コースの公開、受講申込、動画教材の視聴、確認テスト、修了判定、修了証の発行、受講履歴の出力とする。
- 集合研修の会場手配、講師への支払い、人事評価への反映は範囲外とする。

## 2 用語

| 用語 | 意味 |
| --- | --- |
| 受講者 | 研修を受ける社員 |
| 上長 | 受講者の直属の管理職 |
| 管理者 | 研修コースを登録する教育担当者 |
| 受講区分 | 受講者の職位に応じた分類。合格点を区分ごとに定める |
| 視聴済み | 動画教材の再生割合が基準に達した状態 |
| 修了証 | 修了した受講者に発行する証明書 |
| 待機 | 定員を超えた申込を順番待ちにした状態 |

## 3 機能要件

### 3.1 コースの公開と検索

REQ-001 受講者は、研修コースの一覧をコース名の部分一致と受講区分で絞り込んで検索できる。一覧は1ページ20件で表示する。

REQ-003 管理者は、研修コースの登録と編集ができる。登録項目はコース名、受講区分、開講日、定員、受講期限、教材とする。

### 3.2 申込

REQ-002 受講者は、開講日の3営業日前までに受講を申し込める。

定員を超えた申込は待機として受け付ける。空きが出たときは、待機の受講者へ申込順に繰り上げる。

REQ-011 受講者は、開講日の前日までに申込を取り消せる。

申込内容に変更があった場合は、速やかに管理者へ通知する。

### 3.3 受講区分と合格点

REQ-004 受講区分ごとの合格点は次の表のとおりとする。

| 受講区分 | 区分コード | 合格点 |
| --- | --- | --- |
| 新入社員 | NEW | 70 |
| 一般社員 | GEN | 80 |
| 管理職 | MGR | 85 |

### 3.4 教材の視聴

REQ-005 受講者は、動画教材を視聴できる。動画の再生割合が90%以上になった時点で視聴済みとする。

動画は、前回に停止した位置から再生を再開できる。

### 3.5 確認テスト

REQ-006 受講者は、全ての動画教材が視聴済みになった後に確認テストを受験できる。受験は1コースにつき最大3回までとする。

### 3.6 修了と修了証

REQ-007 受講者は、確認テストの得点が受講区分の合格点以上になった時点で修了となる。修了した受講者には、修了証をPDFで発行する。

修了証の再発行は、管理者が行える。

修了後の受講者は、受講アンケートに回答する。回答は無記名で集計する。

### 3.7 通知

REQ-008 システムは、受講期限の7日前に、未修了の受講者へメールで通知する。

必須研修を修了していない受講者に対し、毎月1日に催促メールを送る。

### 3.8 状況の確認と出力

REQ-009 上長は、部下の受講状況を一覧で確認できる。

REQ-012 受講者は、自分の受講履歴を閲覧できる。

REQ-010 管理者は、受講履歴をCSVファイルとして出力できる。

### 3.9 社員情報

受講者の所属部署は、人事マスタから1日1回取り込む。

## 4 非機能要件

### 4.1 性能

REQ-013 コース一覧と受講履歴の画面は、95パーセンタイルで3秒以内に表示する。

REQ-014 同時接続500ユーザーの負荷でも、REQ-013の応答時間を維持する。

### 4.2 可用性

REQ-015 稼働率は月間99.5%以上とする。計画停止の時間は稼働率の計算から除く。

### 4.3 セキュリティ

REQ-016 受講申込、取消、テスト受験、修了証発行の操作ログを監査ログとして1年間保存する。

認証は、社内のシングルサインオン(SAML 2.0)で行う。

### 4.4 使いやすさ

操作は、誰にとっても分かりやすいこと。

### 4.5 バックアップ

データベースのバックアップを毎日1回取得し、30世代を保管する。

## 5 制約

- 利用は社内ネットワークまたは会社貸与のVPN経由に限る。
- 対応ブラウザは、ChromeとEdgeの最新2世代とする。
- 修了証と受講履歴には個人情報を含むため、社外のサービスへ送信しない。
- システムの文言は日本語のみとする。
- 受講期限と開講日の判定は、日本時間の暦日で行う。
