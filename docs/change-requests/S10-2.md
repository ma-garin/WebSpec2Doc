### CR-10-2
- 対象ファイル: 判断の承認 API（共通 I/F v1 の decision.approve を実装する担当）
- 要求: 承認時に web/services/approval_policy.load_approval_policy を読み、forbid_self_approval=true なら起票者と同じ user_id の承認を 403 にする。small_tenant_exception=true かつテナントのメンバー数が small_tenant_max_members 以下のときだけ本人承認を許し、監査の reason に exception_reason を残す
- 根拠: common-contract §4.3（同一 user_id は 403）
- 最小差分: 承認処理の冒頭で規則を読む 1 関数呼び出し
- 互換性: 規則未保存時は既定（禁止）＝ §4.3 と同じ
- 依存先: 無し（S10 で保存 API 済み）
- 検証: 同一 user_id で承認 → 403、例外有効かつ人数内 → 200 と監査に理由
- 期限・優先度: 承認の実装時（高）
