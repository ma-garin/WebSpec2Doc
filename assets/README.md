# 機能アセット一覧

他環境へ渡すための機能アセット。**システム → 画面 → 機能**の順に並べてある。

## 使い方（受け取る側）

1. このリポジトリの zip を GitHub からダウンロードして展開する
2. 下の表から取り込みたい機能を探す
3. そのフォルダを開き、`PROMPT.md` の中身をコピーして Codex / Claude Code に貼る

`PROMPT.md` に検証・配置・配線・受け入れ確認の手順が全部入っている。
