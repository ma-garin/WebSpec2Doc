5. テスト戦略 — 点・線・面・立体・時間・多次元

点

局所欠陥を狙う。エラー推測、探索、静的レビュー。

線

連続領域を切る。同値分割、境界値、負荷の変曲点。

面

論理条件を組む。ドメイン分析、決定表、原因結果。

立体

順序なし因子を扱う。HAYST、直交表、pairwise。

時間

状態と履歴を追う。状態遷移、N-switch、並行性。

多次元

利用文脈を通す。シナリオ、UAT、統計的サンプリング。

各層を独立した流行語として並べず、点で得た欠陥仮説を線の境界、面の論理、立体の因子、時間の状態、多次元の利用文脈へ拡張する。逆に受入で見つかった問題を、下位レベルの再発防止ケースへ還流する。
