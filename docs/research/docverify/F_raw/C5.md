## 勝つための示唆
1. 精度の公開: 指摘の適合率・再現率を自社データ（注入した欠陥の検出率）で公表する。競合は精度を公開していない（発見 1・3）。
2. 観点の明示と追跡: 11 観点のような分類（発見 4）と、観点ごとに「AI で可」「人が必要」を示す。指摘に観点 ID と原文の根拠位置を付ける。
3. 文書間整合（要件↔基本設計、表を含む）を中核機能にする。論文が有望とした領域で、V 字の対応関係（本ツールの立ち位置）に直結（発見 4）。
4. 組織ルールの取り込み: 社内のレビュー基準・用語を設定できる。Seiko Futureworks が既に持つため同等以上が必須（発見 1）。
5. 価格と試用の公開: 競合は価格不明（発見 1）。無料試用と公開価格で導入の摩擦を下げる。QA が自分で試せる粒度にする。
