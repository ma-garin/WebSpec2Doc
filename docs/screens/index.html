撮影条件

  • 対象: このリポジトリの作業ツリー（e2eb61c 時点）を venv/bin/python app.py で起動した実体。
  • ブラウザ: Chromium 141.0.7390.37 / ビューポート 1440×900（モバイル区分のみ 390×844）。
  • 本体アプリ: WEBSPEC2DOC_AUTH_MODE=off（認証オフ運用・ゲスト表示）で 127.0.0.1:8765。
  • 認証画面: WEBSPEC2DOC_AUTH_MODE=required + 空の認証DB で 127.0.0.1:8766 を別に起動し、 初期セットアップ→ログイン→テナント選択の実フローを通して撮影。

  • スクリーンショットは元の PNG（1440px 幅）を WebP q82 に変換。リサイズ以外の加工はしていない。
