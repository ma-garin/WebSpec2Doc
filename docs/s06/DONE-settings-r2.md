## 通した経路（8769・認証オフ・実データ＋検証用レビュー 1 件）
1. GET settings → 既存保存値の表示名が 重大/警告/提案 で返る（移行確認）
2. 画面でプリセット「厳格」→ 帯が「合格 1／不合格 2」→「合格 0／不合格 3」、変わるレビュー名「設定デモ（警告3件）: 合格 → 不合格」、行右に「5 → 0」、保存帯「未保存の変更 1 項目」
3. 理由なし保存: 画面は保存前に止めて案内、API 直叩きは 400 `reason_required`
4. 理由あり保存 200 → 履歴に 1 行（誰・いつ・項目名と前後・理由）→ 再読込で値と履歴が残る

## 要判断
- 判定不能の定義: gate の計算が例外になったレビュー（読み取れない等）だけを数える。未判定の指摘が残るだけでは数えない（gate の規則「未判定は合否に影響しない」に合わせた）
- 重大度の表示名は編集不可（固定）にした。語彙の食い違いを再発させないため。テナントごとの改名が必要なら別途
- 厳格プリセットは 提案 を上限なしのままにした（指示の「重大 0・警告 0・要確認 0」に提案が無いため。要確認 0 は常に固定）
- PUT は values 全体の置き換え（従来どおり）。部分 PUT は他項目を既定へ戻す
