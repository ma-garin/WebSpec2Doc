# 保険契約管理システム 基本設計書

文書ID: INS-BD / 版: 1.0
要件定義書の各要件を処理単位に落とす。保険料の計算は共通部品 PremiumCalc、年齢の判定は共通部品 AgeChecker、通知の送付は共通部品 NoticeSender、監査ログは共通部品 AuditLogger を使う。

## 1. 引受・保険料
DSN-301 契約登録: 申込内容を契約台帳に登録する。保険期間は1年で、契約日から1年後の前日を満了日とする。登録の前に年齢判定（DSN-302）と反社照会（DSN-318）を呼ぶ。 [REQ-301]
DSN-302 年齢判定: AgeChecker を呼び、申込日時点で契約者が満20歳から75歳、被保険者が満0歳から80歳であることを確かめる。範囲外なら登録しない。 [REQ-302]
DSN-303 保険料算出: PremiumCalc を呼ぶ。基準保険料にプラン別の基本料を使い、被保険者の年齢区分の係数（10歳刻み）を掛ける。喫煙者はさらに1.3を掛ける。 [REQ-303]
DSN-304 払込方法別の保険料: 月払は DSN-303 の月額とする。年払は月額の12か月分の合計に0.95を掛ける。 [REQ-304]
DSN-318 反社照会: 申込時に外部の照会サービスへ API で照会する。該当の応答があれば登録を保留にする。 [REQ-318]

## 2. 口座振替・更新・撤回
DSN-305 口座振替処理: 毎月27日（休日なら翌営業日）に、引落データを作って金融機関へ渡す。 [REQ-305]
DSN-306 引落不能処理: 引き落とせなかった契約は、翌月の引落日に再請求する。2か月連続で引き落とせなかった契約は状態を失効にし、失効の通知を NoticeSender（DSN-315）で送る。 [REQ-305]
DSN-307 更新案内: 保険期間1年の満了日の60日前に更新案内を作り、NoticeSender で送る。更新後の保険料は PremiumCalc を更新日時点の年齢で呼んで求める。 [REQ-306]
DSN-308 撤回処理: 契約締結日を含めて8日以内の申込撤回を受け付け、払い込み済みの保険料を全額返金する。9日目以降は受け付けない。 [REQ-307]

## 3. 保険金
DSN-309 入院給付金算出: 入院日数に日額を掛ける。1回の入院につき60日分を上限とする。 [REQ-308]
DSN-310 手術給付金算出: 入院給付金の日額に倍率を掛ける。所定の手術は10倍、重度の手術は20倍とする。 [REQ-309]
DSN-311 支払審査: 請求書類の到着日から30日以内に支払可否を決める。100万円以上の請求は、役員承認の済んだものだけを支払可能にする。 [REQ-310]
DSN-312 保険金支払: 承認後5営業日以内の振込データを作り、支払通知書を NoticeSender で郵送する。 [REQ-311]
DSN-314 告知照合: 申込時の告知書の入院歴を保存しておき、保険金の請求にある入院歴と照合する。告知にない入院歴があれば、契約解除の検討対象として印を付ける。 [REQ-313]

## 4. 解約・変更・管理
DSN-313 解約返戻金算出: 払い込み済みの保険料から、年間保険料に保険期間1年のうち経過した日数（365分の経過日数）を掛けた額を差し引く。 [REQ-312]
DSN-315 通知送付: NoticeSender。契約者が電子メールに同意していればメール、そうでなければ郵送とする。満期・失効・支払の各通知で使う。 [REQ-317]
DSN-316 契約者情報変更: 住所の変更は、本人確認書類の確認済みを条件に反映する。口座の変更は次回の引落から反映する。 [REQ-314]
DSN-317 閲覧権限判定: 契約管理担当と査定担当には契約情報のすべてを、コールセンターには氏名と契約の状態だけを返す。 [REQ-315]
DSN-319 監査ログ記録: AuditLogger を呼び、変更の前後の値・変更者・日時を保存する。保存期間は10年とする。 [REQ-316]
