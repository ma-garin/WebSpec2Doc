# 要件定義書 インターネットバンキング 振込機能

- 文書ID: BANK-REQ-001
- 版: 1.0
- 対象: サンプル銀行 インターネットバンキング（架空）

## 1 目的・範囲

### 1.1 目的

本書は、サンプル銀行のインターネットバンキングで利用者が行う振込について、実現すべき要件を定める。

### 1.2 範囲

- 範囲内: 振込の依頼、確認、認証、受付、予約、取消、履歴照会
- 範囲外: 口座開設、定期預金、外貨送金、ログイン認証そのもの

### 1.3 対象利用者

- 個人利用者
- 法人利用者

## 2 用語

| 用語 | 意味 |
|---|---|
| 利用者 | インターネットバンキングの契約者 |
| 振込元口座 | 振込金額を引き落とす利用者の口座 |
| 受取人 | 振込金額を受け取る相手 |
| 受付番号 | 受け付けた振込に付ける識別番号 |
| ワンタイムパスワード | 1回だけ使える認証用の数字 |
| 振込予約 | 実行日を未来日にした振込 |
| 営業日 | 銀行の休業日を除く日 |

## 3 機能要件

### 3.1 利用条件と口座

- **REQ-001** ログイン済みの利用者だけが振込操作を開始できること。

- **REQ-002** 利用者は振込元口座を、自身が保有する普通預金口座または当座預金口座から選択できること。

- **REQ-003** 利用者は受取人口座を、金融機関名・支店名・預金種別・口座番号（7桁）・受取人名で指定できること。

- **REQ-004** 利用者は受取人を最大50件まで登録でき、登録済みの受取人を選択して振込を依頼できること。

- システムは、受取人口座の名義を照会し、確認画面に表示すること。

### 3.2 金額と手数料

- **REQ-005** 振込金額は1円以上とし、1回あたりと1日あたりの限度額は表1のとおりとすること。

表1 振込限度額

| 区分 | 1回あたり | 1日あたり |
|---|---|---|
| 個人 | 1,000,000円 | 3,000,000円 |
| 法人 | 5,000,000円 | 10,000,000円 |

- **REQ-006** 振込手数料は表2のとおりとし、振込元口座から振込金額と同時に引き落とすこと。

表2 振込手数料

| 振込先 | 手数料 |
|---|---|
| 当行あて | 110円 |
| 他行あて | 330円 |

### 3.3 確認と認証

- **REQ-007** システムは確認画面に、振込元口座・受取人口座・振込金額・手数料・実行日を表示すること。

- **REQ-008** 利用者は確認画面で、ワンタイムパスワードを入力して認証すること。ワンタイムパスワードの有効期限は発行から3分とする。

- **REQ-009** 振込元口座の残高が振込金額と手数料の合計に満たない場合、システムは振込を受け付けず、エラーを表示すること。

### 3.4 受付と実行日

- **REQ-010** システムは振込を受け付けたとき、受付番号を発行すること。

- **REQ-011** 利用者は振込の実行日を、当日から90日先までの範囲で指定できること（振込予約）。

- 15時以降に受け付けた振込は、翌営業日の振込として扱うこと。

- システムは、振込の受付結果を速やかに完了画面へ表示すること。

- システムは、振込結果を利用者の登録メールアドレスへ通知すること。

### 3.5 取消と履歴

- 利用者は、予約済みの振込を実行日の前日まで取り消せること。

- 利用者は、直近13か月分の振込履歴を照会できること。

## 4 非機能要件

### 4.1 性能

- **REQ-012** 確認画面で認証を完了してから完了画面が表示されるまでの応答時間は、通常時に3秒以内（95パーセンタイル）であること。

- **REQ-014** 同時に1000人の利用者が振込操作を行っても、REQ-012 の応答時間を満たすこと。

### 4.2 セキュリティ

- **REQ-013** 通信はTLS 1.2以上で暗号化すること。

### 4.3 監査と保存

- **REQ-015** 振込の受付記録（受付番号・受付日時・振込金額）を7年間保存すること。

### 4.4 可用性と操作性

- サービスの稼働率は、月間で99.9パーセント以上とすること。

- 画面は、利用者が迷わず操作できる品質を備えること。

## 5 制約

- 認証基盤は、既存のログイン認証基盤を利用する。
- 利用環境はパソコンのウェブブラウザのみとする。
- 画面の言語は日本語のみとする。
- 他行あての振込は、全国為替連携サービスを経由して行う。
- 本書の金額は、すべて消費税込みの金額とする。
