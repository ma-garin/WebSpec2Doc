# QAストア会員注文システム 要件一覧

版数: 1.2 / 作成日: 2026-07-26

## 1. 機能要件

| 要件ID | 要件名 | 区分 | 関連機能 | 備考 |
|---|---|---|---|---|
| REQ-001 | 会員はメールアドレスとパスワードでログインできる | 機能 | 認証 | パスワードは8文字以上 |
| REQ-002 | 会員は商品をキーワードで検索できる | 機能 | 商品検索 | 部分一致 |
| REQ-003 | 会員は商品をカテゴリで絞り込める | 機能 | 商品検索 | 3カテゴリ |
| REQ-004 | 会員は商品詳細から注文入力へ進める | 機能 | 注文 | |
| REQ-005 | 注文入力の必須項目が未入力の場合はエラーを表示する | 機能 | 入力検証 | 氏名・フリガナ・メール・電話番号・郵便番号・住所・数量・支払方法 |
| REQ-006 | 電話番号は半角数字11桁以内で必須入力とする | 機能 | 入力検証 | ハイフン不可 |
| REQ-007 | 郵便番号はハイフンなし7桁固定で入力する | 機能 | 入力検証 | 7桁以外は受け付けない |
| REQ-008 | 数量は1以上99以下の整数のみ受け付ける | 機能 | 入力検証 | 範囲外はエラー |
| REQ-009 | 注文確認画面で入力内容を確認してから確定できる | 機能 | 注文 | 戻って修正可能 |
| REQ-010 | 注文完了時に注文番号を発番して表示する | 機能 | 注文 | 形式 ORD-YYYY-MMDD-NNN |
| REQ-011 | 会員は問い合わせ画面から注文に関する質問を送信できる | 機能 | 問い合わせ | 件名・本文必須 |

## 2. 非機能要件

| 要件ID | 要件名 | 区分 | 関連機能 | 備考 |
|---|---|---|---|---|
| REQ-101 | 各画面は3秒以内に表示される | 性能 | 全画面 | 社内回線での実測 |
| REQ-102 | マイページ・注文入力はログイン必須とする | セキュリティ | 認証 | 未ログイン時はログイン画面へ誘導 |
| REQ-103 | robots.txt の Disallow 指定を尊重する | 運用 | 全画面 | 管理画面はクロール対象外 |
