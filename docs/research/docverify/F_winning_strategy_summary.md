# 商用で勝つための要件 要約（2026-10-18）
詳細: [F_winning_strategy.md](F_winning_strategy.md)。最優先の要件は次の 3 つ。

1. 要件定義書⇔基本設計書の対検査（欠落・矛盾候補・追加過多。ID の無い文書でも対応づける）: QuintSpect は要件トレーサビリティが「開発予定」。他の競合も要件文を 1 つずつ採点するか、生成するだけ（C1・C3・C4）。現状の追跡は ID の正規表現頼み
2. 表どうしの突き合わせ: 国内唯一の実測では、表と表を比べる不備を検出できなかった（P10、単一文書）。QuintSpect は docx に非対応（C1）
3. 指摘を原文に結びつけ、AI の指摘は人が判断した後に出す: LLM 支援で人の検出精度が下がった（P1・P6、n=34）。誤検知は利用の最大の障壁（P11b）
最大のリスク: 対検査の精度を日本語で示した根拠が無い。注入した評価セットで再現率を測る前に「勝てる」と言えない（P3b・P10）
