## 設計（検出結果は不変）

- 数値: 単位種別・境界・スコープ・count は単位語でバケット化。同一バケット内を 2-gram の転置索引（prefix filtering、dice>=0.5 を取りこぼさない）で絞る。
- 権限: (action, 条件) でバケット化。対象語なしの文は種別の組で絞る。
- 時系列: 手順の gram（dice 0.6 以上）と対象語の索引で、共通手順が 2 つ以上ありうる組だけ比較。
- 意味: タグ対ごとに集め、gram 索引（dice 0.3）で絞る。
- バケット窓 200 件（MAX_BUCKET）。超過は件数のみをログ（本文なし）。窓を超えた近似重複の組は比較しない。
- 等価性: 旧実装との出力比較（ランダム 40 コーパス）で差 0。benchmark と holdout v1/v2/v3 も同一プロセスで旧新同値。
